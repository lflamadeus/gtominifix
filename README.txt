GTO 迷你修复（gtominifix）
==========================

适用环境
--------
- Minecraft 1.20.1
- Forge 47.x
- Java 17
- 可选依赖：GTOCore（GTOdyssey）、LowDragLib（ldlib）、Functional Storage

功能
----
功能一：修复 GTO 旅行手杖向下传送时的掉血问题。

功能二：修复 GTO 板条箱界面上容器批量转移快捷键失效的问题。
        Ctrl + Shift + 左键 = 同类物品全部转移。
        空格 + 左键 = 整侧转移。

功能三：增加抽屉快捷键，Ctrl + Shift + 左键 = 尽量填满玩家背包（含快捷栏）。

安装
----
把 jar 放进 mods 目录即可。
