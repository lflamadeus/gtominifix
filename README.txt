GTO 迷你修复（gtominifix）
==========================

适用环境
--------
- Minecraft 1.20.1
- Forge 47.x
- Java 17
- 可选依赖：GTOCore（GTOdyssey）、LowDragLib（ldlib）、Functional Storage、AE2（本整合包里由 GTOCore 内嵌提供）

功能
----
功能一：修复 GTO 旅行手杖向下传送时的掉血问题。

功能二：修复 GTO 板条箱界面上容器批量转移快捷键失效的问题。
        Ctrl + Shift + 左键 = 同类物品全部转移。
        空格 + 左键 = 整侧转移。

功能三：增加抽屉快捷键，Ctrl + Shift + 左键 = 尽量填满玩家背包（含快捷栏）。

功能四：修复 AE2 终端界面上「把背包里流体容器中的流体倒进网络」的操作。
        按住 Ctrl + 右键背包里的流体容器 = 把该容器里的流体整罐灌进 ME 网络，
        等效于「用鼠标拿起容器、对着终端界面右键」。
        按住不放拖过一排容器时，每个新碰到的容器各做一次。
        （界面上的容器除外：只认玩家背包里的容器。）

功能五：GTO 流体管道排查工具（只读）。曾经那个「仓里明明有产物、下游也有空位，却不再往外推」
        的卡死，成因是管道的路由表按「管道坐标」缓存、内容却按「流体从哪一面进来」生成，
        于是同一格管道上谁先推谁定表，后来的机器复用别人建的表（表里多一条指回它自己的
        路由，或者少了建表者那一面的目标），表现就是有货不推。**该缺陷已由上游 gtceu 26.10.53
        修掉**（路由表不再依赖调用者 + 取表时剔除指回调用者自己的那条），所以本模组不再打补丁，
        只保留三个只读命令方便你自己确认现场：/gtominifix pipetrace（机器与管道的真实逻辑状态、
        逐面重新寻路、缓存表与游标）、/gtominifix pipeprobe（Forge 能力层概览）、
        /gtominifix pipewatch <秒>（逐秒摘要 + 每 5 秒巡视「有货+能出+未订阅」的机器）。
        结果追加到 logs/gtominifix-debug.log。监听默认关，只在 pipewatch 运行期间才有开销。

安装
----
把 jar 放进 mods 目录即可。
