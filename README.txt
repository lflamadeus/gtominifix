GTO 迷你修复（gtominifix）
==========================

适用环境
--------
- Minecraft 1.20.1
- Forge 47.x
- Java 17
- 可选依赖：GTOCore（GTOdyssey）、LowDragLib（ldlib）、Functional Storage、AE2（本整合包里由 GTOCore 内嵌提供）

功能
----
功能一：修复 GTO 旅行手杖向下传送时的掉血问题。

功能二：修复 GTO 板条箱界面上容器批量转移快捷键失效的问题。
        Ctrl + Shift + 左键 = 同类物品全部转移。
        空格 + 左键 = 整侧转移。

功能三：增加抽屉快捷键，Ctrl + Shift + 左键 = 尽量填满玩家背包（含快捷栏）。

功能四：修复 AE2 终端界面上「把背包里流体容器中的流体倒进网络」的操作。
        按住 Ctrl + 右键背包里的流体容器 = 把该容器里的流体整罐灌进 ME 网络，
        等效于「用鼠标拿起容器、对着终端界面右键」。
        按住不放拖过一排容器时，每个新碰到的容器各做一次。
        （界面上的容器除外：只认玩家背包里的容器。）

功能五：修复 GTO 机器跑久之后「仓里明明有产物、下游也有空位，却不再往外推」。
        成因有两个，都在源头（用 CoreMod 直接改 GTO 的类，不依赖 Mixin）：
        一、机器的邻居缓存会把「这个方向没有邻居」永久记住，之后再也不会重新查看世界——
            机器只要在旁边的管道区块还没加载时看过一眼，那一面就整局都瞎；
        二、机器的自动输出是「订阅制」，订阅掉了只在身边有方块变化时才重建，而管网增删、
            拆分合并、区块加载都不会碰到机器，于是订阅掉了就永远不回来。
        修法：一、不再缓存「没有邻居」这个否定结果（下次自然重新查）；
              二、管网结构变化时，让旁边的机器重新评估一次自动输出订阅。
        装上即生效，没有配置项；排查时可以在 config 目录放一个空的
        gtominifix-pipe-patch.off 把这两个补丁一起关掉。

安装
----
把 jar 放进 mods 目录即可。
